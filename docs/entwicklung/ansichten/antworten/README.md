# Antworten: Möglichkeiten wählen

Eintrag znd-wrp, Fassung 20261117.07. Hauptaufgabe: eine Frage mit einer Möglichkeit beantworten, auf Wunsch mit eigenem Text und Anhang.

- Vorher: beide Möglichkeiten im Blatt gleich gefüllt, ein Tipp sendete sofort, ein danach gewählter Anhang ging verloren; im Eintrag sahen die Möglichkeiten wie Karten aus.
- Nachher: ungewählt Fläche mit Linie, gewählt tonal mit Rand und Haken; **Senden** schickt Wahl, Text und Anhänge zusammen und bleibt gesperrt, bis etwas gewählt oder geschrieben ist. Im Eintrag stehen die Möglichkeiten als Liste.
- Schritte vom Eintrag aus: A senden vorher 2 Tipps (Antworten, A), nachher 3 (Antworten, A, Senden); A mit Anhang vorher nur mit Anhang zuerst (Antworten, Datei anhängen, Datei wählen, A), nachher in jeder Reihenfolge (Antworten, A, Datei anhängen, Datei wählen, Senden).
- Bilder: `vorher-nachher.png` (Blatt, hell und dunkel, Palette orange), dazu je Zustand `vorher-*` und `nachher-*` in 360 × 800 CSS-Pixeln; `farben` heißt Systemfarben, `fest` feste Farben.
- Fassung 20261117.08: jede Zeile ist selbst das Radio (`role="radio"`, `aria-checked`, ein Tab-Halt, Pfeile wählen), kein verstecktes Eingabefeld im `label` mehr; der Satz „Wähle eine Möglichkeit …“ bleibt nach der Wahl unsichtbar im Layout, damit das Blatt nicht rutscht. Optik unverändert.
